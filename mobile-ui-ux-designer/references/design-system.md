# Android design-system specification

Define semantic color roles, typography roles, spacing scale, shape scale, elevation, icon rules, and motion principles. Document components with anatomy, variants, states, behavior, content constraints, accessibility semantics, and examples of correct use.

Account for dynamic type, dark theme, edge-to-edge layouts, system bars, keyboard insets, localization expansion, RTL when applicable, compact and expanded widths, and landscape only when the product supports it.

Use Material 3 as a behavioral and accessibility foundation, not as a requirement that every product look identical.
