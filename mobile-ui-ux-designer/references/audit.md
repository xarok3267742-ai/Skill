# Mobile UX audit

Evaluate by journey, not only by screen.

1. Comprehension: Can a new user explain the screen and next action quickly?
2. Hierarchy: Is one primary action visually dominant where appropriate?
3. Navigation: Are destination, back behavior, and current location predictable?
4. Feedback: Does every action produce timely, unambiguous feedback?
5. Recovery: Can users recover without losing entered work?
6. Accessibility: Check contrast, scalable text, labels, focus order, motion, and touch targets.
7. Consistency: Do identical concepts share labels, components, and behavior?
8. Trust: Are prices, subscriptions, data use, risks, and irreversible effects clear before commitment?

Classify findings as blocker, high, medium, or polish. Include location, evidence, user impact, and a concrete fix. Separate observed defects from hypotheses.
